**Usage**
- `xarast-cli render <in.xar> -o <out.png> [--zoom PCT] [--dpi N] [--width PX] [--height PX] [--frame drawing|page] [--quality final|draft] [--quiet]`
- `xarast-cli render <in.xar|DIR>... --out-dir DIR`: renders several files, including every `.xar` under a directory, and prints a summary.
- `xarast-cli smoke-open <in.xar|DIR>... [--quiet]`: prints nodes, diagnostics, visited nodes, primitives and pending items (text, shapes, images, live, clips-unsupported) per file.
- Exit codes: 0 ok, 1 usage, 2 import failed, 3 render or write failed.
