The CPU half is now measured through the Draft/Final scheduler (XARA-US-0006, `cargo bench -p xarast-app -- viewport`; see `perf.md`). At 105k objects and 1080p, a zoom notch takes 1.5-1.6 ms. A pan takes 5-7 ms at fit page but 51-57 ms when zoomed into the drawing. The integrated-GPU figure this task asks for is still open, because the render thread has no GPU renderer behind `FrameRenderer` yet.
