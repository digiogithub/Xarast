GPU half measured via XARA-T-0050 on 2026-09-23, load average 1–3.5. Each probe step is one scripted intent per frame: a 23.4×7.7 px pan, or a 1.05× zoom. Documents were the synthetic 250k-node document (~105k paths) and ProbeX16.xar. Samples are 300 per run after a 10-frame warm-up.

Live window (`xarast --probe pan|zoom`) on COSMIC, no vsync. COSMIC tiles the window, so the canvas was 1796×1338 (2.4 MP, more than 1080p). Figures are input → presented p50/p99, with input → GPU idle in brackets:
- Intel iGPU, GPU tiles: synthetic pan 0.50/1.31 (2.24/5.52), zoom 0.37/0.54 (2.13/2.75); ProbeX16 pan 0.37/1.06 (1.56/4.68), zoom 0.33/0.53 (2.05/8.72).
- RTX 4000 Ada, GPU tiles: pan 0.31–0.44/2.6–3.2, zoom 0.30–0.32/2.5.
- CPU tier on either adapter: 2.4–3.5 / 3.2–5.0.

Offscreen (`examples/canvas_probe`), input at 120 Hz, input → GPU idle p50/p99:
- Intel at 1080p: pan 1.8–1.9/4.0–5.5, zoom 1.6/3.2–4.2.
- Intel at 4K: pan 3.4–3.7/7.7–9.6, zoom 2.0–2.9/5.8–6.9.
- RTX at 4K: pan 0.8/2.7–4.6, zoom 0.5–0.6/0.9–1.0.
- The CPU tier at 4K on the iGPU is 35/41 ms, which is the T-0052 upload cliff. That only affects the fallback tier.

Every p99 is well inside 16 ms on the iGPU at both sizes, so the budget is met. Tables are in docs/memory/perf.md under "Pan and zoom end to end". The CPU-backend half was already recorded in XARA-US-0006.
