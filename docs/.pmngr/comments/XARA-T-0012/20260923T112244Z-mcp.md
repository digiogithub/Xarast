Done: 848249d (app) and 0db31f5 (cli).

- `HeadlessResult` now carries `walk: WalkStats`, `scene: SceneStats`, `zoom` and `view: ViewParams`.
- `HeadlessOptions` takes `frame: HeadlessFrame` (`Session`, `FitDrawing`, `Fit(rect)` or `Fixed { zoom, centre_on }`) and `dpi: Option<f64>`. This replaces `fit_drawing: bool`.
- `viewport::drawing_rect` excludes page nodes: it covers the active spread's visible, non-guide layers. `drawing_or_page_rect` falls back to the page when there is nothing to draw or the drawing has zero area, and both `ZoomTo(Drawing)` and fit use it. `content_rect` keeps the old whole-tree bounds, which the render thread uses for culling.
- `xarast-cli render` dropped `ink_rect`, the hand-set viewport and the second walk. Its output is unchanged, and it still reports `[not drawn: ...]` from the headless walk.
