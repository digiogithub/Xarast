Fixed in `31c153e` (render: cut strokes to the band before dashing them).

- `stroke_cull` cuts the centre line to the band plus the stroke's reach, testing in device space, so degenerate views still cull. Lines are clipped and curves split. Each kept run is dashed from its own arc length, so the phase is preserved, and a closed subpath cut open is rejoined at its seam as the dasher does. It engages only when the stroke reaches more than 256 px past the band, so no golden changed.
- Work budget: dashes × flattening cost per dash ≤ 10⁶ segments. Past that the pattern is dropped and the stroke drawn solid. Culling alone cannot bound a very wide stroke.
- `fuzz_display_list`: the geometry bound (±1e7 mp) and the dash limit (≤ 2 000) are lifted.
  - Run 1 found the wide-stroke OOM above (fixed).
  - Run 2 found an `i64` overflow in bilinear image sampling (`x0 + 1` at a saturated coordinate), fixed with `saturating_add`.
  - Run 3 on the final code was clean: **317 008 execs in 601 s**, peak RSS 813 MB, no artefacts.
- Tests: `stroke_cull` unit tests sample stroked outlines to compare cut and whole strokes, covering phase, closed seams, odd patterns, curves and degenerate transforms. `tests/stroke_cull.rs` renders a 20 000 000 mp dashed line at deep zoom and compares it with a short line in phase (≤ 1/255).
