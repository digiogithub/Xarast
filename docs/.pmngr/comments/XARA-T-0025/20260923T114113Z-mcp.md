Diagnosis (render agent): I found two faults.

1. **xarast-render, fixed in `d392269`**: `DisplayList::build` moved paint mappings into device space but left graduated and bitmap *transparency* mappings in document units. Every transparency gradient therefore evaluated as one flat level. This file uses them throughout.
2. **The black itself comes from the walker/attribute defaults, not the renderer**: the frame path at the end of the layer (`TAG_PATH_RELATIVE_FILLED_STROKED`, 12 pt black line, **no fill attribute**) is emitted as an opaque black `Fill` over the whole drawing. I skipped that one command with a debug hack and the whole design appears. Filed as **XARA-T-0037** with the record-level details, plus a second suspicion about the default gradient repeat mode.

The acceptance criteria (sphere visible, pinned by a test) now depend on XARA-T-0037 (xarast-app/xarast-doc), so I leave this task open for that owner.
