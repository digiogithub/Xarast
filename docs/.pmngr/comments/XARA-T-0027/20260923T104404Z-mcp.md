Done in `ed7eff4` (worktree branch `worktree-agent-a0481830ffd58ceca`).
`xarast_shell::gpu_errors`: `GpuErrorSink` is installed with `on_uncaptured_error` and the device-lost callback; it logs, counts and forwards the error to the app as `ShellEvent::GpuError` (the viewer shows it in the status bar). The `GpuRecovery` policy reconfigures the surface for 3 failing frames, then backs off exponentially (16 ms up to 2 s) and never exits.
Evidence: a unit test raises a real validation error on the RTX 4000 and asserts it is counted, not fatal. `XARAST_INJECT_GPU_ERRORS=6 xarast --screenshot … BLUECAR.xar` logged 4 errors, went through reconfigure ×3 and one back-off, captured the frame with the status message showing, and exited 0.
