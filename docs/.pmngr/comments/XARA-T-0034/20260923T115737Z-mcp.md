Fixed in `7273b96`, with `67579ff` for the band size.

- When the area spans too few bands to occupy the machine, the interactive configuration splits it into column tiles: at most 32, each at least 64 px wide. The count depends only on the area, never on the thread count. Each tile renders in its own buffer in parallel and is copied back. A tile edge clips coverage exactly as a dirty-rect edge already did.
- A new determinism test renders a clipped, layered strip tiled and serially and requires identical bytes. On the 100k strip, tiled and untiled were also byte-identical. The deterministic configuration never tiles, so export and the goldens are untouched.
- Interactive bands are now 512 KiB (16 per 1080p frame instead of 8).

`strip/render_1920x40_100000` (new criterion bench): **9.4 ms → 1.17 ms**. A tall 40 px column strip was already multi-band: 1.2 ms.
