Done in 3ba98d6 (branch `worktree-agent-a0d4f492948290eea`): `paint.rs::bitmap_repeat(own, attr)`. The fill's own tiling wins when set (a `.xarast` fill may carry one). Otherwise the fill-mapping attribute decides, at face value, and unset (`Tiling::None`) means repeat. The same rule applies to bitmap transparencies. Unit test `a_bitmap_fill_takes_the_mapping_attribute_and_tiles_by_default`. With XARA-T-0129's decoding, `Fill Types simple.xar`'s bitmap row renders single, repeating and mirrored ("Xara"/"araX") tiles in the headless render. The `.xarast` round trip still loses the mirror, which is XARA-T-0109, a writer task.
