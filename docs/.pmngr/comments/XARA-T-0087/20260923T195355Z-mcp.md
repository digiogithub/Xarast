Autosave + recovery done in `xarast-app::autosave` / `AppState::{tick, offer_recovery, emergency_shutdown}` — commit b099fe4, shell wiring b9e7d48. **The NDJSON journal (F6.6) is not done**: the document model has no serialisable command form, so it is filed separately.

- Layout: `$XDG_STATE_HOME/xarast/autosave/<id>/{snapshot.xarast, holder, origin}`; holder written before the snapshot. Snapshot = the same off-thread `SaveJob` (deflate 1, no thumbnail).
- Policy: modified, idle 2 s, no gesture, 60 s since the last snapshot (or since it became modified). The shell wakes for the next due time.
- Deleted on a save that leaves the doc clean, undo back to clean, close, quit. Kept by SIGTERM (`emergency_shutdown` writes a fresh one).
- Recovery at start: holder dead / other boot, snapshot strictly newer than the origin (older ones deleted; a live process's left alone) → "Recover unsaved work" (Recover / Discard / Later). Recovered docs are modified, named after the origin, keep the entry until saved.
- Tests: `tests/save.rs` (policy timing, crash → recover → save deletes entry, decline/postpone, close vs signal), `autosave.rs` unit tests, shell `a_signal_autosaves_the_work_and_exits`.
