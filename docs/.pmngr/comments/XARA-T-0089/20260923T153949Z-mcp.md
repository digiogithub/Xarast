Done in 8b0834d (`core: add a per-node foreign-baggage store to the document model`).

Design: `xarast_doc::foreign::{ForeignBaggage, ForeignAttr, ForeignChild, ForeignChildKind, ForeignMarks}` in a side table on `Tree` (`SecondaryMap<NodeId, Arc<ForeignBaggage>>`, like the bounds cache), so `NodeData` stays exactly 64 bytes. Read API `Tree::{foreign, foreign_arc, foreign_iter, foreign_len}`; mutation only through the new undoable `Action::SetForeign` (`Tx::set_foreign`, `Tx::mark_foreign`) and `DocumentBuilder::foreign` at build time. Keyed by NodeId, so baggage rides through move/group/change layer; a deleted node keeps it while the history retains it; `destroy_subtree` drops it; `snapshot`/`restore` carry it across the id remap. The canonical digest folds it in only where present (bit 16 of the flags word), so documents without baggage digest exactly as before.

Tests: the §8.7 battery (move, recolour, group, change layer, delete, undo, redo) with exact digests; digest sensitivity; marks; destroy; snapshot; builder; the undo/redo property test now also sets, clears and marks baggage. Edit auto-marking (F4.7) is left to W4.
