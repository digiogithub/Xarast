Resolved with option (a), in 967da9a (reader) and 71fe240 (corpus test).

**Localisation.** The reader gives each ink node one attribute child per slot whose resolved value differs from `default_for(slot)`; containers get none (a `<g>`'s hoisted paint is pushed down and dropped). Rules for what SVG merges: `fill-opacity` = colour alpha × transparency alpha (a literal colour is taken as opaque, a palette colour or twin says its alpha); `xarast:blend` goes to the fill transparency when there is a fill; a mask's padded box gives back an unstroked element's line width.

**Normal form** (`svg::normal_form`, documented in `svg/read/normal.rs` and `docs/memory/xarast-format.md`): text, one fact per line — metadata; palette in order; every non-attribute node in document order with id, kind and fields at the profile's precision (paths as the writer's path data in the spread frame); per ink node the *resolved* attribute stack projected through the writer's own paint code with definitions inlined by content and derived data (baked stops, flat approximations) dropped; baggage; Opaque nodes with their children. Independent of where attributes sit, of hoisting/classes, of def ids.

**Tested**: `tests/svg_read.rs` (fixture: NF equal and first re-save byte-identical), `tests/svg_roundtrip.rs` over the corpus: NF equal for 50/59; the other 9 differ only by objects the writer drops under Opaque nodes (XARA-T-0108, listed in the test and checked to be the only difference).
