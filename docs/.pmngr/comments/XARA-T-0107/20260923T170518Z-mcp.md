Done in the W4 reader (967da9a, `svg/read/style.rs`, `build/root.rs`, `build/paint.rs`).

- Cascade: inherited < presentation attribute < class rule < `style`, with `inherit`; `xarast:fill-ref` / `stroke-ref` are inherited pseudo-properties and are also applied from `<xarast:paint-class>` by class (any class name, taken from the `<style>`, not assumed `cN`); `<xarast:paint-class>` is a consumed def. A `class` attribute is consumed only when all its classes are the document's rules; otherwise kept as foreign. A twin only applies when the palette colour resolves to the element's actual colour (a stale ref after a recolour is ignored).
- A `<g>`'s hoisted values are never model attributes of the group (asserted).
- The ClipView clip shape inside `<clipPath>` is read with an empty inherited style (inline paint, point 5).
