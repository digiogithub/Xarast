Done in 2edbc2b. Palette components now use the shortest decimal that reads back as the same f32. Key colours name their palette colour (`xarast:stop-refs`, `colour-refs`, `contone-refs`). Baked stops and flat approximations are computed from the keys as they are written. `meta.xml` now counts the bitmaps actually written. The first re-save is byte-identical for 59/59 files, and the `>= 54` bound is replaced by strict equality. Spec: research/06 §6.14.
