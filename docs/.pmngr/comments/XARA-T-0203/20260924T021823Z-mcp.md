Status note from XARA-T-0221: the dirty-region bullet of this task no longer needs `ColourUses`. The render thread now compares the scene on screen with the new one (`xarast_render::scene_damage`), so a palette redefinition repaints exactly the objects whose resolved paint changed. That is pinned by `xarast-shell/tests/edit_damage.rs::redefining_a_named_colour_repaints_its_users_only`. The walker still resolves colours through `Colour::resolve(table).to_rgba8()`: the `PaletteResolver` half of this task, the packing band, the golden regeneration and the cache-key epoch are all still open.
