## Report — PDF text is text (branch `worktree-agent-ab43a0cf8dd7e9d59`, NOT merged with the working branch yet)

Commits: `db46282` (shared embedding layer in `xarast-text`), `0416a42` (PDF), `efe6087` (`TextOutput`/`--text outlines`), `6dc4b52` (docs: `export.md` "Fonts", `text.md` "Font embedding").

**How:** the walker keeps each painted run's glyphs (face, gid, transform, cluster text, underline) and hands them to exporters as `SourceScene::text`; the PDF translator finds a run from its fill op by the identity of its outline path (no render-crate change). Every face used is subset once (`subsetter`) and written as `Type0` → `CIDFontType2`/`FontFile2` or `CIDFontType0`/`FontFile3 CIDFontType0C`, `Identity-H`, widths, descriptor, `ToUnicode`. Flat fills → `0 Tr` text, gradients → `7 Tr` text clip + shading; runs the ladder cannot paint as text (bitmap fill, rasterised transparency, variable instance, underline under translucent paint, stroke-only) keep their outlines/pixels plus invisible `3 Tr` text, so all text is selectable. A face whose `fsType` forbids embedding is never embedded: outlines + `Compromise::FontNotEmbedded`. `Capabilities::embeds_fonts = true`.
