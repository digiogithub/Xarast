Fixed on branch `worktree-agent-a975e287ffaece6ec` (4 commits on top of 8068f92: 9626e5a, 0b4e1fa, 119e995, 763c011).

1. **Transparent destination.** `blend::composite` now treats a destination with alpha a_d as that opaque colour over a_d of the pixel and as nothing over the rest. Over nothing, every family acts as Mix: the source at alpha coverage·(1−t). For Mix this is exactly source-over. An opaque destination takes the old code path byte for byte.
   - **Second bug found:** the PNG and WebP exporters wrote premultiplied surface bytes as if they were straight colour, which darkened partly transparent pixels a second time. Fixed with `xarast_render::unpremultiply_rgba_in_place` in `xarast-io/src/raster.rs`. `render_export_strips` now also premultiplies `ExportJob::background`, which is documented as straight. A 50 % white square now exports as (255,255,255,128) in both PNG and WebP.
2. **Caps.** The CPU stroker now sets `with_start_cap` and `with_end_cap` separately.
3. **Dash offset.** The stroker now uses `xarast_geom::reduced_dash_offset`, which is now public. It applies on the whole-path route and in `cull_stroke_input`, which now takes the phase.
   - **Latent seam bug fixed along the way:** a tail run that starts inside a dash has its first dash emitted last by the dasher, so the seam join was skipped.

Goldens: 119 of 120 are unchanged. `layer_nested` moved: 1 904 px, max 16/255, lighter. Its inner Mix layer lands on the transparent area of the outer isolated layer. It was regenerated with `XARAST_UPDATE_GOLDEN=1`.

Tests: `tests/stroke_ends_and_alpha.rs` (7), blend unit tests (2), stroke_cull offset/seam test, and the io raster PNG+WebP test.

Gates: fmt, clippy -D warnings, workspace tests with the corpus (1615 passed, 0 failed, 1 ignored), cargo deny, and `cargo build --locked` all pass.

Not done:
- `pdf/rasterise.rs` still renders over black and white and unmixes. That is still correct, but one render plus unpremultiply would now suffice. I left it for a PDF task.
- `LayerKind::Plain` pops still composite with coverage 255 and ignore the layer's alpha. Only the synthetic corpus uses this.
