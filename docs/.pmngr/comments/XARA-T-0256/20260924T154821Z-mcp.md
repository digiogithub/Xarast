Done on branch `worktree-agent-a2af95ba6ff41af94` (from `claude/xara-xtreme-rust-port-ktggmu` 7ce0197), commits 46213c8, d90565b, d961a78, 4e57720.

- **Mesh repeat:** `paint::mesh_uv` folds both frame axes through `apply_repeat`. `mesh3_channel` and `mesh4_channel` are the only definition of the meshes, and PDF calls them too. `Simple` gives the same bytes as before.
- **Tiled meshes mirror.** Evidence comes from the preview embedded in `Fill Types simple.xar`, rendered at its 52×113 size and scored per cell (mean |Δ|). Mirror scores 25.3/23.2/23.4 on the tiled four-colour cells, against 51.0/31.8/29.3 for plain repeat and 64.9/48.3/42.8 for clamp. On the tiled three-colour cells mirror scores 35.4/38.7, repeat 47.1/35.5 and clamp 52.9/56.9. The stripes and checkers in the original's cells only appear with mirroring. `mesh_repeat` now returns `Repeat::Mirror` for every mapping except simple.
- **Mesh transparencies** are now `TranspSource::Mesh { mapping, repeat, levels: MeshLevels }`. They are evaluated per pixel on the colour mesh's frame and corner order, tiled the same way, and composited in the family of `c0.mode` (before this they were a flat mean in Mix). `tests/mesh_transparency.rs` checks them against the colour mesh in all four repeat modes (±1).
- **GPU:** there is no GPU paint pass (render TODO 2 is deferred), so there is no shader to change.
- **Goldens:** 12 `gradient_mesh*_{repeat,repeathq,mirror}_*` goldens were re-blessed. They had encoded the bug. 20 `fill_blend/mesh*_*_graduated` goldens were also re-blessed: the mesh cells now use a real mesh transparency.
- **PDF:** a mirrored mesh is drawn as one sampled function over all its periods, which is exact for four colours. Plain repetition and mesh transparencies are rasterised.
- **SVG** (`bake.rs`): rows are mirrored per period and use `spreadMethod=reflect`. Mesh transparencies become luminance masks.
- **Corpus export-check:** 59 references, 118 comparisons, 0 failures. SoftShadow.svg went from 4.1 to 1.20, so its limit is removed.
- **Gates:** all green. fmt, clippy (0 warnings), 1985 tests passed / 0 failed / 1 ignored with the corpus, the doc build, and cargo deny.
- **Tile parity:** a frame now passes if every difference is 1/255. The worst case, mesh3 mirror, has 259 px at 1/255.
