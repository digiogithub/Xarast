Fixed on branch worktree-agent-ab11390e1eb00042e (d92959c and 89b72be, on top of 6aa348b).

**Root cause (in the test, not in production).** `xarast_app::fonts::shared()` is a process-wide `OnceLock`, and the first caller decides what it holds. With `XARAST_FONT_DIR` unset, that is the *system* fonts. Opening a session already calls it: `Session::adopt` fits the view to the page, and `viewport.rs` measures text stories with `fonts::document`. In `text_path_caret.rs`, only `the_tool_follows_the_path_through_the_session` called `set_shared(pinned)`, and it ignored the returned `bool`. The other four corpus tests in that binary open TextCurve.xar without doing so. When one of them reached `shared()` first, the session's text tool laid the story out with the system's Noto Sans, but the test built its caret map with the pinned subset. The result was exactly the reported drift: (1212814, 1052089) vs (1211518.2, 1050715.9), about 1,300 mp per axis, at line 353. T-0281, T-0293 and the overlay cache played no part. Adding `fonts::shared()` before `set_shared` reproduces it deterministically.

**Fix.** The test file's `fonts()` helper now caches the pinned `Arc` in a `OnceLock`, calls `set_shared`, and asserts `Arc::ptr_eq(&shared(), &pinned)`. Every test calls it before `open()`, so whichever test runs first installs the same service. I audited `text_tool`, `text_convert`, `text_infobar` and `text_clipboard`: all their tests already install the pinned fonts before opening a session. The production code needs no change, because the shell uses `shared()` everywhere and it is fixed once per process.

**Evidence** (the whole `text_path_caret` binary, `--test-threads=64`, 48 `yes` CPU hogs):
- before: 158/200 runs failed, all at line 353 with the same coordinates. Idle: 0/60.
- after: 0/200 under the same load, and 0/100 idle.

**Gates:** fmt 0; clippy 0; `XARAST_XAR_CORPUS=… cargo test --workspace` 0 (1952 passed, 0 failed, 1 ignored, 146 result lines); cargo deny 0 (advisories, bans, licenses and sources ok); `cargo build --locked` 0.

Memory: `docs/memory/text.md` now has invariant 8 (the shared-font rule for app test binaries) and a dead-end entry.
