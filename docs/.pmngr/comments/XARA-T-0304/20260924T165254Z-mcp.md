Report (branch `worktree-agent-a4a382d47af800d4a`, commits 9df56ed, 78290cc, 72b27e6 on d00e783; not pushed).

**Design.** Uses the T-0281 substitution/repair path. There is no second async mechanism and no shell change.
- `render`: `ImageRef::deferred(w, h, budget, source, standin)` creates a store with no level resident. A `Materialise` sampler (export, thumbnails, headless, tests) produces the base in place, byte-identical to an eager image. A `Substitute` sampler draws a stand-in kept outside `levels` and stamps the image. `rematerialise` then produces the base and the whole pyramid. `rematerialise` now works with the store unlocked, for every store, so a render never waits behind a decode or an evaluation. `scene_damage` compares images with `eq_without_producing`, so it never runs an evaluation on the render thread.
- `core`: the session's walker is `with_deferred_derived()`. A derived image of at least `DEFER_MIN_PIXELS` (1 Mi px) is registered deferred. Its stand-in is the drag's last proxy of that same chain (shared, not copied), or the chain evaluated at the preview level (never below level 1). `derive` and the deferred source share `derived_source`, so both produce the same bytes. Other walkers still evaluate eagerly.
- Stale results after undo/redo: a result belongs to the store that asked for it, and a repair is owed to one generation. No stale picture gets published (tested).

**Timings** (`xarast-cli bench photo`, 6000x4000, 1280x800, release build):
- Release walk: 223–373 ms before (load 8–14), 0.2 ms after (load 33–36) and 0.11 ms in the pr gate (load 80–105).
- Release frame: 25–34 ms, about the same as a slider frame.
- Exact frame: 235–366 ms after the release.

- The settled frame equals a fresh walker's full-resolution render byte for byte, and every repainted rectangle lies on the photograph.
