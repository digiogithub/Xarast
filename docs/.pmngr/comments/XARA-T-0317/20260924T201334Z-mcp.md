Implemented on branch `worktree-agent-a796de9879e8562b6` (from d3b41bc): 92ff248 (io: filter), 2157d53 (io: limits dropped), 3a32876 (docs).

**Choice: an SVG filter only, no raster mask.** The filter alone lands under the default limit of 4 in both resvg and headless Chrome. It stays vector, and it needs no renderer at save time, so the `.xarast` base SVG gets it too (same mapper, both dialects). `svg/effect.rs` provides `FilterChain` + `Region` for other effects (shadow/glow/bevel). If a raster fallback is ever needed, it goes beside `SvgOptions::derived_bitmaps` (export only).

The chain, with r = size/2 and σ = r/2: SourceAlpha → colour channels → erosion by the union of 4 rectangles (r cos φ, r sin φ) at φ = 11.25°, 33.75°, 56.25° and 78.75°, via `feMorphology` + `feBlend darken` (a minimum, so the shape is close to a disc) → back to alpha → `feGaussianBlur` → profile as a 33-entry `feFuncA` table (1 − P(1 − a)) → `feComposite in SourceGraphic`, sRGB. The reader recognises `xarast:filter="feather"`, drops the def and the `filter` attribute, and reads the feather from `xarast:feather`.
