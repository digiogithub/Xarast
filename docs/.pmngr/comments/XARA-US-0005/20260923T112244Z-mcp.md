- `xarast_app::schedule::QualityScheduler` is a pure state machine with the clock passed in: Draft while input arrives, one Final 120 ms after the last input, and new input cancels a Final that is waiting or in flight. The first frame of a document is Final. Tests use a synthetic clock and no sleeps.
- `schedule::Canvas` joins it to `RenderThread` + `Session` (`note`, `pump` returns the deadline for the timed wake-up, `take_latest`, `is_settled`).
- Render thread: `FrameJob` now carries `Arc<Scene>` + a scene epoch + an ink rect, and the worker builds the display lists. It keeps the last frame: a pan scrolls it and draws only the exposed strips (a fractional Draft pan snaps to whole pixels), and a Draft zoom resamples it (the uncovered border shows the backdrop until the Final). A Final is drawn in up to 4 full-height columns and abandoned between columns for newer input. Scrolled and column-drawn output matches a one-call render to within 1/255 (tests).
