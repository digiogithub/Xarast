Bench: 74b3eee, `cargo bench -p xarast-app -- viewport`. Numbers are recorded in `docs/memory/perf.md` (a229dfb).

The synthetic document has 105 852 objects, each filled and stroked (224 218 primitives), at 1920x1080 with the CPU interactive config. Each figure runs from the intent to the collected frame through `Canvas`. Two runs at load 7-15 agreed to within 3 %.

| | fit page | zoomed 3x |
|---|---|---|
| pan (Draft) | 5.3-6.6 ms | **51-57 ms** |
| zoom notch (Draft) | 1.5-1.6 ms | 1.5-1.6 ms |
| Final after idle | 284-287 ms | 340-363 ms |
| full Draft, no reuse | 231-235 ms | 262-270 ms |

Against the 16 ms budget: zoom passes. Pan passes at fit page but **fails by ~3.4x when the view is full of ink**. Of that frame, ~35 ms is two `DisplayList::build` scans (XARA-T-0033) and ~15 ms is strips rasterised on one core (XARA-T-0034). Both are in xarast-render.
