**Decision (docs/memory/render.md, "The GPU decision"): no GPU rasteriser now. Rasterise on the CPU, keep the pixels on the GPU as tiles, and let the GPU move them (option a).** The WGSL paint/blend pass (b) is deferred until the trigger in XARA-T-0051 fires. `vello` (c) is rejected until it targets our `wgpu` and fits the iGPU budget.

Evidence from the reference machine. The spread covers 4 runs at load 5–25; each GPU figure is wall clock up to poll(wait):

| | Intel Arrow Lake iGPU | RTX 4000 SFF Ada |
|---|---|---|
| today: upload the whole 1080p frame | 0.54–1.6 ms | 0.61–0.89 ms |
| (a) pan, 40 resident tiles | 0.47–1.4 ms | 0.08–0.21 ms |
| (a) Draft zoom 1.3× / 0.5× | 0.37–1.8 / 0.71–2.0 ms | 0.08–0.15 / 0.15–0.47 ms |
| **today: upload the whole 4K frame** | **23–27 ms** | 2.6–3.5 ms |
| (a) 4K pan, 144 resident tiles | 1.5–3.0 ms | 0.30–0.54 ms |
| (b) floor: upload 64 MiB of A8 coverage | 27–33 ms | 5.4–6.9 ms |
| (c) vello full 100k frame (W0) | 72–86 ms | 7.8–8.0 ms |

(c) dependency cost: two wgpu versions add **+4.08 MiB** stripped (probe binary 4.27 → 8.35 MB) and **+46 crates** (127 → 173), and 9 more crates end up duplicated. The two wgpu instances cannot share a device.

**Parity:** the GPU tile composite is **byte-identical** to `compose_cpu`. That holds for 960 of 960 composites on each of the Intel iGPU, the RTX and lavapipe: the 120-scene corpus in 32² tiles, composited eight ways. Separately, a frame assembled from tiles that were rasterised one by one differs from the whole-frame render in 15 of 120 cases (≤ 17 px each). So a Final frame at rest is still rendered whole and then cut into tiles.

**Built (xarast-render, `gpu` feature):** `compose::{TileGrid, TilePlacement, compose_cpu, source_texel}`, `backend::gpu_tiles::GpuTileCache`, `tests/parity_tiles.rs` and `benches/tiles.rs`.

**Integration:** XARA-T-0050 (shell/app wiring and the capability ladder). Follow-ups: XARA-T-0051 (the deferred WGSL pass) and XARA-T-0052 (the iGPU large-upload cliff).

Acceptance status: the parity test passes on real hardware. Degrading gracefully to the CPU is specified (no device → today's path / `compose_cpu`) but is wired only in XARA-T-0050.
