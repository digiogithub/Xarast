### Incident to report
The first isolated run activated `dconf-service` on the private bus with the host `DCONF_PROFILE=cosmic`, so three settings were written to the maintainer's `~/.config/dconf/cosmic` database: `/org/gnome/mutter/experimental-features=['scale-monitor-framebuffer']`, `/org/gnome/desktop/interface/enable-hot-corners=false`, `/org/gnome/shell/welcome-dialog-last-shown-version='46.0'`. The GTK portal may also have rewritten `/org/gtk/settings/file-chooser` (window-size (1203, 921) is the nested dialog's size). None of these keys affects COSMIC. My reset attempt did not take effect (the file is unchanged since 13:25:27), and a second attempt was blocked by permissions, so I left it. To restore, as the maintainer:
```
DCONF_PROFILE=/usr/share/dconf/profile/cosmic dconf reset /org/gnome/mutter/experimental-features
DCONF_PROFILE=/usr/share/dconf/profile/cosmic dconf reset /org/gnome/desktop/interface/enable-hot-corners
DCONF_PROFILE=/usr/share/dconf/profile/cosmic dconf reset /org/gnome/shell/welcome-dialog-last-shown-version
```
Every later run used a private `DCONF_PROFILE`; the cosmic db was not touched again.
