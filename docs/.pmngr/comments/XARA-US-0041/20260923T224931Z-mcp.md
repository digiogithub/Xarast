## Report: W8.6 colour editor (branch `worktree-agent-a2c7987ba97e864f7`, 6 commits on 5985c3e)

**Commits**: `16bad30` core: History::discard_redo · `c3e4838` core: ColourEditorModel + EditCommand::Palette · `8e3e913` core: re-export PaintSlot · `bc8cb21` ui: colour editor (field, numbers, derivation) · `c43998f` ui: shell routing · `af5de2e` docs: colour.md decisions 19–23, ui.md "Colour editor".

**What was built**
- T8.6.1 (XARA-T-0238): `xarast_app::colour_editor`. The targets are the selection's fill or line (with nothing selected, the current attribute) or a palette entry. A drag works like this: the first `Preview` opens a bus gesture, every preview is applied at once and coalesces into one step, and `Commit` closes it. `Cancel` (Esc) undoes the step and `discard_redo` drops it, so the digest, labels, state serial and redo list all come back. `Intent::ColourEditor`, `Session::colour_editor_view`.
- T8.6.2 (XARA-T-0239): `xarast_ui::colour_field`. The HSV field is S×V with a hue strip. RGB/CIE show two channels on the field and the third on a strip; which channel goes on the strip is selectable. CMYK shows two of C/M/Y, with key entered as a number. Grey has only a strip. The field is painted as vertex-coloured meshes, not textures. A test proves this is exact for RGB/HSV.
- T8.6.3 (XARA-T-0240): numeric entry with units: RGB 0–255, hue in degrees, everything else in per cent. Values are clamped and each field has a name. Arrow keys step a focused field or strip by 1 % (10 % with Shift).
- T8.6.4 (XARA-T-0241): the derivation editor covers kind, parent (the entry itself and its descendants are excluded), tint %, shade S/V shifts, and a link with per-component "follow the parent". An HSV link that follows the hue is the "HSV delta". It uses `PaletteCommand::Derive`, which runs reparent + link mask as one step.
- T8.6.5 (XARA-T-0242): editing an object that uses a named colour breaks the link for that object only. "Redefine ‘name’" is a separate step: it switches the target to the entry. "Apply to fill/line" puts the named colour on the selection as a live reference. This also closes the palette half of XARA-T-0212 (`EditCommand::Palette`: Create/Redefine/Rename/Derive/Delete).

**Tests**: `xarast-app/tests/colour_editor.rs` 13 (60-event drag = 1 step, Esc exact, hue kept at S=0, link vs redefine, tint drag, cycle refused, HSV link, locked layer, …). There are also 7 unit tests in `colour_field`, 8 in `panels::colour` (including a pointer press/drag/release → previews + one commit), accessibility tests for the editor and the derivation editor plus a keyboard-only test, and one shell mapping test.

**Gates** (exit codes): fmt 0, clippy 0, workspace test with corpus 0 (1666 passed, 0 failed, 1 ignored, 116 binaries), deny 0, build --locked 0.
