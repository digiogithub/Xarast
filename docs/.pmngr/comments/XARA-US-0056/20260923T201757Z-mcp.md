Round 1 done on branch `worktree-agent-a9c0e9a773d4f239c`. Commits: d45937c (model, registry, encoders), 0bce21d (CLI), 6925c74 (docs).

- **T11.1.1 and T11.1.2** (`crates/xarast-io/src/model.rs`): `ExportRequest`, `ExportArea` (Selection, Page(Option<NodeId>), Spread, Drawing, Rect), `Background` (Transparent, Paper, Colour) and bleed. `ExportSizing` links pixels, physical size and dpi with one pinned axis; `resolve` and `edit(SizingEdit)` implement it, rounding half away from zero. 100 mm at 300 dpi comes out as 1181 px, and a 20-triple table covers the .5 cases. One keystroke recompute costs 23 ns (budget 100 µs).
- **T11.1.3** (`registry.rs`): the `Exporter` trait, `Capabilities` (vector, alpha, multipage, embeds_fonts, has_dpi, lossy, deterministic, max_side, streams) and a `Registry` with `with_builtin`, `get`, `for_extension` and `all`. There is no `.xar` entry, and `XAR_EXPORT_REFUSAL` cites architecture §3.5.
- **T11.1.4** (`options.rs`): serde-serialisable PNG, JPEG and WebP options. They use `#[serde(default)]` so export hints can round-trip later (T11.1.5).
- **T11.1.7**: `xarast-cli export` with every option as a flag; `.xar` is refused.
- **Deviation**: the model lives in `xarast-io`, not `xarast-app`, because the app depends on io. The app-side part is the `ExportSource` trait.
- **Filed**: XARA-T-0192, which implements `ExportSource` for `Session` and builds the File › Export dialog from `Capabilities`. Until then the CLI carries a `SessionSource`.
- **Not done**: T11.1.5 (hints in `meta.xml`), T11.1.6 (batch export), T11.1.8 (the dialog).
