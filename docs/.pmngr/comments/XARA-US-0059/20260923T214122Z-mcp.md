## Round 1 done: vector PDF 1.7 export (T11.4.1–T11.4.4, plus the soft-mask part of T11.4.5)

Branch `worktree-agent-a38332d64d343eaf3`, based on 353e880:
- e8b3d9a render: add DisplayList::with_commands and an export list rasteriser
- dd507fc io: export PDF 1.7 through a pdf-writer facade
- 6827919 cli: export PDF with --raster-dpi, --blend and --no-compress
- 6568fa6 io: name the renderer task the PDF rasteriser works around
- 180ecd7 docs: record the PDF spike, fidelity matrix and ladder in memory

**What was built**
- T11.4.1 spike: chose `pdf-writer` 0.15 over `krilla` 0.8.2. krilla cannot carry a baked ramp as a sampled function and has no mesh shadings; it uses `f32` tiny-skia geometry (not kurbo), pins skrifa 0.42 and needs MSRV 1.92. The table is in `docs/memory/export.md` § PDF.
- T11.4.2: the `PdfWriter` façade in `crates/xarast-io/src/pdf/writer.rs` is the only code that names the crate. It interns graphics states, functions and shadings, and writes no dates or IDs, so output is deterministic.
- T11.4.3: fills (non-zero and even-odd), clips, and strokes drawn in document units under the object's transform (width, cap, join, mitre, dash with offset, hairline). Strokes with mismatched caps or gradient paint are drawn from their outline.
- T11.4.4: exact natively: linear and radial shadings, diamond (two axial shadings), the four-colour mesh (a 2×2 sampled function), and repeats. The ramp table is baked into a type-0 function. Approximated and reported: conical (a 256-wedge Gouraud fan) and the three-colour mesh (a 33×33 grid).
- T11.4.5 (part): graduated transparency is written as a luminosity soft mask, flat opacity as `ca`/`CA`, and layers as transparency groups.
- Ladder step 3 runs on the CPU backend. It rasterises perspective gradients, bitmaps and images, the Positive/Negative fill rules, and every non-Mix family (together with its backdrop). Each case gets its own `Compromise::Rasterised` naming the object. New variants: `Rasterised`, `Approximated`, `BlendModeApproximated`. New options: `PdfOptions { version, rasterise_dpi, blend_fidelity (Exact default | PreferNative), compress }`.
