## Description
The renderer half of XARA-US-0052 (`crates/xarast-render/src/resample.rs`):

- One sampler for image fills, placed bitmaps and bitmap transparencies (`TranspSource::Image` gains a `Filter`).
- Filtering in premultiplied linear light (phase 10 §W10.4), compositing unchanged in encoded sRGB.
- Nearest / bilinear / high-quality kernel; the HQ kernel chosen by a comparison harness (T10.4.3).
- Mip pyramid (2×2 box, linear light), level from the Jacobian; per pixel for perspective.
- Aligned (1 texel per pixel) fast path, pinned to point sampling (T10.3.7).
- Contone per texel through a 256-entry table (T10.3.4); repeat modes (T10.3.3) and bitmap transparency (T10.3.5) through the same sampler.
- GPU parity (T10.4.5) by construction; the new corpus cases are in `parity_gpu_cpu`.
